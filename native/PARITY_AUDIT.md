# Native 与 WinUI3 对齐审计

基准：`winui3/WindowsExtendQuickSetting` 当前源码与实际界面。状态定义：

- `完成`：native 有真实系统调用、状态刷新、失败反馈，并已运行验收。
- `缺失`：native 尚无对应入口或行为。
- `假实现`：只有界面或近似行为，未达到 WinUI3 语义。
- `未验证`：已有实现，但尚缺真实设备或界面证据。
